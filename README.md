# IndicConformer-600M-Multi (AI4Bharat): installer copy for BST Auto Captioning

An unmodified copy of [ai4bharat/indic-conformer-600m-multilingual](https://huggingface.co/ai4bharat/indic-conformer-600m-multilingual)
(revision `2a77d305038dfc502fd9464e7d028b90381976cb`), MIT licensed by AI4Bharat, so the BST Auto Captioning installer can
download it in one step. The model files are in the release as one tar archive split into parts below 2 GB;
`SHA256SUMS.txt` holds the checksums. See `LICENSE.txt` and `ATTRIBUTION.txt`, and please cite the original authors as
the model card asks.
